# Dashboard em Power BI - Análise de Indicadores

Projeto desenvolvido em Power BI como parte da minha transição para a área de Dados.

## Objetivo
Transformar dados em informações visuais para facilitar análises e apoiar decisões.

## Principais recursos utilizados
- Tratamento de dados
- Modelagem básica
- Criação de indicadores (KPIs)
- Visualizações interativas
- Filtros segmentados

## Insights possíveis
- Acompanhamento de resultados
- Comparação entre períodos
- Identificação de tendências
- Apoio à tomada de decisão

## Arquivos do projeto
- .pbix com dashboard editável
- Imagem do painel
- Base de dados (quando disponível)

## Ferramentas utilizadas
- Power BI
- Excel
- GitHub

## Sobre mim
Profissional em transição de carreira para Dados, estudando SQL, Power BI e análise de dados diariamente.
